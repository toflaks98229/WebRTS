# LPC 에셋 출처 표기

`tools/lpc-attribution.mjs` 가 LPC 저장소의 `sheet_definitions` 에 기록된
저작권 정보로부터 자동 생성합니다. 직접 편집하지 마세요.

출처: <https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator>
