# 용병단 — Mercenary Company

Battle Brothers 를 모델로 한 웹 게임. **캠페인 지도**에서 용병단을 이끌고 다니다
적 무리와 부딪히면 **헥스 전술 전투**로 전환됩니다.
빌드 도구 없이 순수 HTML + ES 모듈 + Canvas 2D 로 동작합니다.

## 실행

ES 모듈은 `file://` 에서 로드되지 않으므로 로컬 서버가 필요합니다.

```bash
npm start
```

그 뒤 <http://localhost:5173> 을 엽니다. (의존성 없음 — `serve.js` 는 Node 표준 라이브러리만 씁니다.)

캐릭터 스프라이트를 처음 받으려면:

```bash
node tools/fetch-lpc.mjs
```

에셋이 없어도 게임은 그대로 실행됩니다 — 렌더러가 자체 도형 렌더링으로 되돌아갑니다.

## 조작

### 캠페인 지도

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 그 지점으로 행군 (적 무리를 클릭하면 추격) |
| 우클릭 / `Esc` | 행군 중지 |
| `Space` | 일시정지 · 재개 |
| `1` / `2` | 보통 / 빠름 |
| `Tab` | 용병단으로 카메라 복귀 |

### 전투

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 빈 칸이면 이동, 적이면 선택한 기술로 공격 |
| 우클릭 / `Esc` | 선택한 기술 해제 |
| `1`–`9` | 기술 선택 |
| `Space` | 턴 종료 |
| `Q` | 대기 (이번 라운드 순서를 뒤로 미룸) |
| `Tab` | 현재 유닛으로 카메라 복귀 |

공통으로 휠은 확대·축소, 우클릭 드래그와 방향키(또는 `WASD`)는 화면 이동입니다.

## 캠페인

- 섬 하나가 절차적으로 생성된다 — 지형은 고도와 습도 노이즈로 결정되고,
  그 위에 **마을·읍·도시**가 서로 며칠 거리를 두고 놓이며 **길**로 이어진다.
  거친 지형에는 산적 **야영지**가 숨는다.
- 시간은 실시간으로 흐른다. 행군 시간은 지형에 따라 3~11시간이고 **길 위에서는 절반**이다.
- 적 무리는 야영지 근처를 배회하다 **4칸** 안에 들어온 용병단을 추격한다.
  같은 칸에 서면 전투가 시작되고, 지형에 맞는 전장이 생성된다.
- 전투 결과는 지도로 돌아온다 — **부상과 깨진 방어구는 그대로 남고**, 전사자는 영원히 사라지며,
  승리하면 적의 장비를 노획한다.
- 마을에 머물면 상처와 장비가 서서히 회복된다. 규모가 클수록 빠르다.
  `하루 휴식` 은 하루를 통째로 건너뛴다.
- 야영지를 비워도 며칠 뒤 새 무리가 채워진다.

## 계약과 살림

마을에서 **마을 들어가기** 를 누르면 게시판·고용·상점·창고가 열린다. 머무는
동안 시간은 멈춘다.

- **계약** — 두 종류가 걸린다.
  - *산적 소탕*: 지정된 야영지의 무리를 없앤 뒤 **의뢰한 마을로 돌아가** 보고해야 보수를 받는다.
  - *대상 호위*: 목적지 마을에 도착하면 그 자리에서 삯을 받는다.
  기한을 넘기면 계약은 파기된다. 게시판은 며칠마다 새로 걸린다.
- **고용** — 지원자는 미리 굴린 실제 능력치를 보여준다. 같은 배경이라도 사람마다
  다르므로, 값을 치를지는 숫자를 보고 정한다. 큰 도시일수록 좋은 사람이 온다.
  정원은 9명.
- **상점** — 무기·방패·갑옷·투구를 사고판다. 큰 도시일수록 비싼 물건을 취급한다.
- **창고** — 전투에서 노획한 여분 장비가 쌓인다. 팔거나 다른 단원에게 넘길 수 있다.
  넘길 때 밀려난 장비는 다시 창고로 돌아온다.

**급여는 매일 새벽 자동으로 나간다.** 못 주는 날이 이틀 이어지면 단원이 떠난다
(마지막 한 명은 남는다). 초기 자금은 900 크라운이다.

## 전투 규칙

- **행동력(AP)** 매 턴 9. 이동은 지형에 따라 2~5 AP, 한 단계 오르막마다 +2 AP.
- **피로도** 행동마다 누적되어 방어력과 주도권을 깎고, 한계에 닿으면 기술을 못 쓴다. 턴마다 15 회복.
- **지배 지역(ZOC)** 적에게 인접한 칸에서 벗어나면 추가 AP·피로도를 지불한다.
- **방어구** 피해는 방어구 내구도를 먼저 깎고 일부만 체력에 들어간다.
  둔기는 관통(`armorPen`)이, 도끼는 방어구 파괴(`armorMult`)가 강하다.
- **부위** 25% 확률로 머리에 맞고 피해가 1.5배가 된다.
- **고저차** 높은 곳에서 치면 명중 +10/단계, 피해 +15%/단계. 능선은 시야를 막는다.
- **사기** 확신 → 침착 → 동요 → 붕괴 → 패주. 아군의 죽음과 중상이 판정을 부른다.
- **영구 사망** 쓰러진 단원은 돌아오지 않는다. 승리하면 적의 장비를 노획해 생존자가 장비한다.

## 구조

```
index.html            화면 구성
css/style.css         UI 스타일
serve.js              의존성 없는 정적 서버
tools/fetch-lpc.mjs   LPC 스프라이트 선별 다운로더

tools/lpc-attribution.mjs  에셋 출처 표기 자동 생성

src/
  main.js             앱 셸 — 캔버스, 지속되는 용병단, 씬 전환, 입력 라우팅
  scenes/
    campaignScene.js  지도 씬 — 시간 진행, 행군 명령, 조우 감지
    battleScene.js    전투 씬 — 입력, 연출, AI 진행, 전과 보고
  core/               시드 RNG, 이벤트 버스
  hex/                헥스 좌표계(hex.js), 픽셀 변환(layout.js), 경로탐색(pathfind.js)
  data/               지형 · 월드 지형 · 장비 · 기술 · 유닛 템플릿 (전부 순수 데이터)
  battle/             grid(높이맵) · unit · combat(명중·피해) · battle(턴 진행) · ai
  campaign/           world(맵 생성) · campaign(시간·부대·조우·계약·급여)
                      company(명부·금고·창고) · contracts · bands · loot
  render/             camera · renderer(전장) · worldRenderer(지도) · sprites(LPC) · effects
  ui/                 overlay(공용) · hud(전투) · worldHud(지도) · settlementPanel(마을)
```

모델 계층(`src/battle`, `src/hex`, `src/data`, `src/campaign`)은 DOM 을 전혀 참조하지
않아 Node 에서 그대로 시뮬레이션을 돌릴 수 있습니다. 밸런싱과 지도 생성 검증은
그 방식으로 했습니다.
